<H1>GitHub User Activity</H1>
<p>Sample solution for the <a url="https://roadmap.sh/projects/github-user-activity">github-user-activity challenge from [roadmap.sh](https://roadmap.sh/).

<H2>How to run</H2>
<H3>Clone the repository and run the following command:</H3>

```
git clone https://github.com/kirlsix/GitHub-User-Activity
cd .\GitHub-User-Activity\
```
<H2>Run the following command to build and run the project:</H2>

```bash
go build -o github-activity
# ./github-activity username
./github-activity kirlsix
```
